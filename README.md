# 🚀 Featured Projects

## 📡 AI-Powered Telecom Neighbour Management System

### 🤖 AI / NLP + Telecom Automation

A domain-specific AI-powered chatbot and automation system designed for telecom neighbour management.

### Key Features

- Developed a custom **PyTorch-based NLP model** for intent classification and natural-language command processing.
- Built an intelligent input-understanding pipeline using **fuzzy matching** to handle spelling variations and uncertain State/JC inputs.
- Integrated the AI layer with telecom business logic for:
  - Neighbour validation
  - PCI validation
  - TAC validation
  - Invalid neighbour analysis
  - Cleanup preview
  - Safety-controlled deletion
- Implemented **multi-turn conversation context** using session-based history.
- Designed a **verified conversation data pipeline** for future model retraining and continuous improvement.
- Added safety mechanisms to prevent unsafe neighbour deletion operations.

### Technology Stack

`Python` `PyTorch` `NLP` `REST APIs` `Fuzzy Matching` `MySQL` `Spring Boot` `React` `Tailwind CSS`
